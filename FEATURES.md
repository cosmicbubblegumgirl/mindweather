# Features

## Presentation flow

Landing page → Check Your Weather → Cognitive Storm → adaptive plan → “I don’t know where to start” → one tiny action → mistake growth → constellation activation → Brain Forecast.

## Core surfaces

- Weather Station: six manual states plus four-signal suggestion.
- Brain Weather Lab: live signal dials, seven learner intents, channel-or-calm recipes, and weather-sized handoffs.
- Bloopy: app-aware navigation, local next-step help, authenticated online answers, opt-in web search, and visible sources.
- Resource Compass: local study-path inference and weather-, task-, topic-, and preference-aware resource ranking.
- Printable Studio: a seven-day timetable, active-recall workbook, task breakdown, brain dump, and Future-Me handoff.
- Adaptive Plan: weather-shaped sequence, Assignment Autopsy, Timeline, and Roulette.
- Tasks: validated creation, filtering, drag-and-drop status, subtasks, deadlines, and session handoff.
- Focus: adaptive timer, pause/resume, session reflection, focus quality, and a weather-themed Pomodoro with weather-shaped work and rest lengths.
- Learning evidence: forecast observations, Study DNA corrections, concept constellation, mistake growth, and Ghost Notes.
- Support: Teach Bloop, Quiet Rooms, Freeze Mode, calendar, journal, notifications, universal search, privacy controls, local authentication, and an iOS/Android install guide.
- Wellbeing: anxiety and attention reflections, a 90-second breathing reset, clear non-diagnostic language, and help lines for South Africa and international users.
- Demo depth: Classroom-informed sprint tasks, an Experience Learning subject, and 200 deterministic study records make the forecast, garden, notes, calendar, and journal useful from the first visit.

## Local-first guarantees

Planning, navigation, resource ranking, focus tools, and printable generation continue in the browser during a temporary network interruption. Protected account data syncs through Supabase when the connection returns. Bloopy never attempts online search unless the learner switches web access on.
